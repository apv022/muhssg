muhssg

A static site generator for personal sites.
Markdown in, fast static HTML out. One binary. No Node, no runtime.

Read the guide → View on GitHub ↗

install

~

$ go install github.com/apv022/muhssg@latest
$ muhssg new site my-site && cd my-site
$ muhssg serve
✓ built 9 pages in 226ms
serving my-site at http://127.0.0.1:4321/ — Ctrl+C to stop

Prefer a binary? Grab one for Linux, macOS or Windows from releases.

what you get

Static first
Pages are plain HTML that works with JavaScript off. Add TypeScript or Alpine.js only where a page needs to move.
Collections
Every folder in content/ gets a list page, prev/next links, tags and an RSS feed.
Assets, bundled
CSS imports and JS/TS are bundled by esbuild, minified and content-hashed. npm packages work.
Swap the vibe
Themes stack. A theme can be one CSS file that restyles everything below it.
Shortcodes
Drop {{ "{{<" }} youtube {{ ">}}" }}, figures, notes and your own snippets straight into Markdown.
Images
Local images become responsive srcsets. Phone photos are rotated and stripped of GPS data.
Pagination
paginate: 10 splits long lists into /page/2/, /page/3/ and so on.
Highlighting
Code is coloured at build time, with separate light and dark styles and no JavaScript.
Favicons
One square image becomes the .ico, Apple and Android icons and a web manifest.
SEO, done
Canonical links, Open Graph tags, a sitemap, robots.txt and redirects.
Live reload
muhssg serve rebuilds on save and shows build errors right on the page.
Safe builds
Output is swapped in only after a build succeeds. Deleted pages disappear.
Link checker
muhssg check catches broken links and missing anchors.

one line, new look

The same page, before and after adding a theme that is a single CSS file of colour tokens:

# muhssg.yaml
theme: [solar, default]

a site

my-site/
├── muhssg.yaml
├── content/      Markdown and HTML pages
├── templates/    html/template layouts
├── assets/       CSS, JS, TS: bundled
├── static/       copied as-is
├── data/         YAML and JSON
└── themes/       layers of all of the above

No config is required beyond a title. Every folder is optional, and each one does what its name says.
